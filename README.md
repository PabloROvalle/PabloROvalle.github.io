## Publish on GitHub Pages
1. Upload/replace `index.html`, `styles.css`, `script.js`, `publications.json`, `assets/`, `scripts/sync_publications.py`, and `.github/workflows/sync-publications.yml` at repository root. **Keep the folder names intact**.
2. For ease, use GitHub's `Add file → Upload files` with drag-and-drop of the unzipped folders. If the browser cannot upload hidden `.github` folder, use `Add file → Create new file`, enter `.github/workflows/sync-publications.yml` in the file name field, and paste the contents.
3. Create a free OpenAlex account at https://openalex.org/ and copy the API key at https://openalex.org/settings/api. **Do not put the key in site files.**
4. In repository **Settings → Secrets and variables → Actions → New repository secret**, set the name `OPENALEX_API_KEY` and the value to your key.
5. Open **Actions → Sync publications from ORCID-linked OpenAlex author → Run workflow** and wait for success. Confirm `publications.json` contains actual records. This also triggers GitHub Pages deployment from `main`.
6. Future runs occur once daily on GitHub Actions; scheduled jobs can run late or be disabled after long inactivity. Check Actions if updates stop. Manual Run workflow works anytime.

## If you want exactly the items listed in ORCID
This setup uses ORCID as an author identifier, but downloads works from OpenAlex. For a perfect ORCID works mirror, ORCID's public API requires OAuth credentials and a different GitHub Actions job. Never embed credentials in client-side JavaScript.
